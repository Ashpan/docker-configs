Items in Downloads/completed that qBittorrent no longer tracks AND that aren't hardlinked anywhere else (Media library etc.)
A name showing up here means two things are both true: qBittorrent has stopped seeding it (removed from its torrent list), and no other file on the NAS shares its data via a hardlink — so deleting it actually frees disk space, unlike most of Downloads/completed which is hardlinked into Media/ and would free nothing if removed. This does not mean the content was successfully imported — it may simply have never been picked up by Sonarr/Radarr. Check each name against your library before deleting. This page is read-only; delete manually via SSH or your file manager.
